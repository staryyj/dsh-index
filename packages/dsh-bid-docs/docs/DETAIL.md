# 投标方案生成（dsh-bid-docs）

把招标资料包变成两套交付物：

| 交付物 | 版式 | 页数 |
|---|---|---|
| 技术标（施工组织设计） | A3 横版、小四宋体 1.5 倍行距、暗标 | 4 页 |
| 附表 | A4、4 张表 + 2 张图、结构固定 | 5～6 页 |

## 用法

1. `inspect`：解压招标资料，识别最新版招标文件（自动取补遗后最高版本）、抽取工期/造价/保证金/资质/暗标/技术标页数，汇总清单工程量，并把公告页渲染成图供核对；
2. 补 `plan.json`（项目全称、道路、长度、工期、结构类型 road/blacktop 等）；
3. `build`：出总平面图、工艺流程图、进度横道图，生成技术标与附表，转 PDF 并报页数。

## 规则

- 工程量必须来自清单，不按长度×宽度估算；
- 横道图：整月等宽、首末月按实际天数缩窄（最窄 22%）、年份条带居中、只写计划开工+工期；
- 附表结构不变，只换单元格文字与两张图；
- 暗标稿不得出现单位名称、人员姓名、签章。
