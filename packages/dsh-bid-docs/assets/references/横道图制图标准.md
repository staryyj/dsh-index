# 附表三《施工进度计划横道图》制图标准（2026-11-17 定稿）

> 以后所有项目的附表三横道图，一律按本标准生成，不再另行调整版式。
> 生成脚本：`make_gantt.py`（同目录），调用方式见文末。

---

## 一、必须具备的信息

| 项 | 说明 |
|---|---|
| 计划开工 | **必须**，格式「2026 年 12 月 20 日」 |
| 计划工期 | **必须**，格式「450 日历天」 |
| **计划竣工** | **一律不写**（不需要，也不要出现） |
| 工序横道 | 每行一个工序，注明「起~止天」 |
| 关键节点 | 一行橙字，按 42 字自动折行 |

## 二、时间轴规则

1. **整月等宽**：每个自然月占一列，整月（30/31 天全覆盖）宽度相同；
2. **首月/末月按实际天数定宽**：
   列宽 ＝ 整月宽度 ×（该月实际施工天数 ÷ 该月天数），最窄压到 **22%**；
   - 例：12 月 20 日开工 → 12 月只做 12 天 → 约 39% 宽
   - 例：10 月只做到 7 日 → 约 23% 宽（最窄）
   - 例：9 月做到 15 日 → 约 50% 宽（比 7 天的宽一倍）
3. 月份名写「**12月、1月、2月…**」，位于本列正中，不带年份；
4. 月份边界按**真实日历**计算，工序跨月时横道按天比例落在当月列内。

## 三、年份条带

1. 时间轴上方一条通栏浅蓝底条带（高约 38px@2600 宽），每年一段，段间画竖线；
2. **年份文字在段内居中**（不是靠左）；
3. 段宽 ≥150px：横排「2027 年」，字号 20；
   段宽 <150px（通常首年只有 12 月一个月）：**竖排两行**（上「2026」下「年」），字号 15，仍居中。

## 四、横道与标注

| 项 | 规范 |
|---|---|
| 横道颜色 | 深蓝 `#1F4E79` |
| 行底纹 | 隔行浅灰底（`#F7F9FC`），便于对行 |
| 工期标签 | 「起~止天」灰色小字，写在横道右端；横道贴右边时改写在左端 |
| 工序名 | 左侧栏，宋体 22（@2600 宽） |

## 五、输出参数

| 项 | 值 |
|---|---|
| 画布宽 | **2600 px** |
| 分辨率 | **300 dpi** |
| 插入 Word 宽度 | **19.84 cm**（约 333dpi 有效精度） |
| 图外边框 | 深蓝 3px |
| 右下角注 | 「注：与施工组织设计进度安排一致」 |

## 七、脚本用法

```python
from datetime import date
from make_gantt import gantt

gantt(
    out='gantt_out/40_gantt.png',
    rows=[('施工准备', 1, 20), ('管线施工', 21, 200), ('收尾验收', 201, 240)],
    start=date(2027, 1, 5),     # 计划开工日
    days=240,                    # 计划工期
    note='关键节点：第20天临建完成｜第200天管线贯通｜第240天竣工验收',
)
```

生成的 PNG 直接按 19.84cm 宽插入附表三的图片位置（替换旧图，不动表格结构与页数）。

## 八、检查清单（每次生成后对照）

- [ ] 抬头只有「计划开工 + 计划工期」，**没有计划竣工**
- [ ] 整月等宽，首末月按天数缩窄，最窄 22%
- [ ] 年份在条带内**居中**，窄段竖排两行
- [ ] 月份名只写「x月」
- [ ] 横道右端标签完整，未出界
- [ ] 关键节点未折字、未出界
- [ ] 输出 2600px / 300dpi，插入 19.84cm
- [ ] 替换后附表文件页数不变
