# 招标文件解析与废标红线

## 一、先定位最新版招标文件

压缩包里常见：`A33xxxx.招标文件.V2.pdf`、`补遗一/A33xxxx.招标文件.V4.pdf`、`招标文件修改通知.pdf`、`招标文件澄清通知.pdf`。

**规则：取补遗后最高版本号**（V4 > V3 > V2），并且**必读修改通知与澄清通知**——里面常有勾选框变化、条款替换、日期调整。

## 二、必抽的 9 个参数（前附表 2.x / 3.x）

| 参数 | 位置 | 用途 |
|---|---|---|
| 工程名称、编号、标段 | 公告 2.1 | 所有文件抬头 |
| 工期（日历天） | 前附表 2.3 | 技术标进度图、附表三 |
| 本次招标建安造价 | 公告 2.2 | 工程量表、报价 |
| 最高投标限价 | 前附表 | 报价上限 |
| 投标保证金金额 | 前附表 2.x | 转账/保函 |
| 资质等级、建造师等级 | 前附表 3.1 / 3.7 | 资格审查 |
| 专职安全员人数 | 3.9 | 资审 |
| 技术标页数上限 | 前附表（搜"技术标文件…页"） | 排版页数 |
| 是否暗标 | 全文搜"暗标" | 去痕规则 |

## 三、暗标判定与去痕

**判定**：全文搜「暗标」，出现 ≥1 次即为暗标；同时看「不得出现单位名称、人员姓名、标识」类条款。

**必删清单**（技术标/施工组织设计）：
- 封面上的投标人名称、法定代表人、签章
- 页眉页脚里的公司名、LOGO、电话
- 正文中的"我公司""XX 建设有限公司"
- 人员姓名（项目经理、技术负责人写"项目负责人"即可）
- 印章、签字图片、水印
- 文档属性（作者、公司）

## 四、废标红线检查表（逐项打勾）

**资格类**
- [ ] 资质等级满足且动态核查"合格"
- [ ] 安全生产许可证有效
- [ ] 项目负责人：注册在本单位、等级满足、有 B 证、**无在建工程**
- [ ] 专职安全员人数达标且持 C 证
- [ ] 省外企业进浙备案（如适用）
- [ ] 未被列入黑名单/失信被执行人

**文件类**
- [ ] 投标文件按要求的章、节、顺序编制
- [ ] 技术标页数未超限
- [ ] 暗标文件无任何可识别信息
- [ ] 签字、盖章位置齐全（法人、造价工程师、执业专用章）
- [ ] 投标有效期 ≥ 招标文件要求（常见 90 日历天）
- [ ] 保证金金额、形式、**从基本户转出**、到账时间
- [ ] 电子标：CA 锁、加密、上传成功回执

**报价类**
- [ ] 报价 ≤ 最高投标限价
- [ ] 安全文明施工基本费 ≥ 招标文件下限（低于即否决）
- [ ] 暂列金额、暂估价按招标文件填写，不得改动
- [ ] 工程量清单不得增删项、不得改计量单位

**技术类**
- [ ] 工期、质量目标承诺与招标文件一致
- [ ] 主要设备、人员与招标文件附表要求匹配

## 五、与旧模板逐页对照

拿一份已完成的项目（如 202 页模板）做底，按章节建立映射：

```
资格审查资料 P1–119
技术标         P120–124（含施工组织设计、附表1–4）
资信标         P125–186
商务标         P187–202
```

对照输出三列：**模板页 → 本项目页 → 差异（新增/删除/替换/文字改动）**。
差异项优先看：封面、目录、承诺书、声明函、报价封面、签章页。

## 六、中小企业声明函怎么办

看两处：前附表「是否专门面向中小企业」勾选 + 否决条款里是否有"未提供声明函"。
- 勾"否"且无相关否决条款 → **不需要提供**（38/39 就是这种情况，别多放）；
- 勾"是" → 必须提供，且格式按招标文件给定模板。

## 七、输出

1. `params.json`：九项参数 + 暗标判定
2. `checks.md`：红线检查表（逐项 ✅/❌/不适用）
3. `diff.md`：与旧模板的逐页差异
4. 风险提示：把"不确定/需招标人澄清"的点单列一节
