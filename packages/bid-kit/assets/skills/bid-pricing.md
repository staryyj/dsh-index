# 报价与资信核查

## 一、报价三条硬线（低于/高于都废标）

| 红线 | 判断方法 | 后果 |
|---|---|---|
| 投标报价 ≤ **最高投标限价** | 前附表给出的限价（含税） | 超过即否决 |
| 安全文明施工基本费 ≥ **招标文件下限** | 招标文件常在否决条款里写"低于 145019 元（不含税）即否决" | 低于即否决 |
| 暂列金额、暂估价 | 必须按清单原值计入，不得改动 | 改动即否决 |

**计算方法**：报价 = 分部分项 + 措施项目 + 其他项目 + 规费 + 税金；核对时逐项与"已审定的招标控制价/清单"比对，差价异常要说明。

## 二、报价文件的签章要求（高频否决点）

看招标文件 10.1（否决投标条款）里报价部分：

- [ ] 投标总报价封面：**注册造价工程师签字 + 执业专用章**（浙江宁波项目常见要求）
- [ ] 法定代表人签字或盖章
- [ ] 已标价工程量清单：编制人、核对人、审核人签字
- [ ] 投标函附录中的报价大小写一致

> 模板里若没有造价师签章位，要自己加，不能空着交。

## 三、投标有效期与保证金

| 项 | 检查点 |
|---|---|
| 投标有效期 | 承诺 ≥ 招标文件（常见 90 日历天），不足即否决 |
| 保证金金额 | 与大写金额一致 |
| 保证金形式 | 转账 / 银行保函 / 保险保单，按招标文件允许的形式 |
| 转账账户 | **必须从投标人基本账户转出**（审核流水） |
| 到账时间 | 开标前到账，凭回执 |

## 四、资信标内容（与招标文件评分办法对应）

```
1. 投标人一般情况（营业执照、资质、安许）
2. 近年财务状况（通常近 3 年报表 + 审计报告）
3. 评分业绩汇总表（近 3～5 年同类项目，含中标通知书+合同+验收）
4. 投标人、拟派项目负责人信用情况   ← 注意：有的项目没有这一项
5. 项目管理班子配备情况表（人员证书、社保）
6. 招标人要求提交的其他资料
```

**易错点**：37/39 的评分办法没有"信用情况"这一节，模板里多出来要删；38 有，必须保留。

## 五、业绩认定要点

- 时间范围（如"2023 年 1 月 1 日以来"）以**竣工验收日期**或中标通知书日期为准，看招标文件口径
- 规模指标：合同金额、道路长度、管径等，必须≥要求值
- 证明材料三件套：中标通知书 + 施工合同 + 竣工验收证明
- 分包业绩一般**不认**

## 六、资信标评分自查表

| 评分项 | 分值 | 自查 |
|---|---|---|
| 报价 | 60～70 | 不超限价、不低于成本 |
| 业绩 | 5～10 | 证书齐全、指标达标 |
| 项目经理 | 2～5 | 同类业绩、无在建 |
| 信用 | 0～5 | 无黑名单、无失信 |
| 技术标 | 通过制 | 页数、暗标、内容完整 |
| 荣誉/其他 | 0～5 | 按评分办法逐项 |

## 七、输出

1. `pricing-check.md`：三条硬线 + 签章清单 + 有效期/保证金核对
2. `credit-check.md`：资信标逐项对照评分办法
3. 风险提示：把"需造价人员确认""需招标人澄清"单列
