# 投标工具包（bid-kit）

五个技能，覆盖投标从读招标文件到出稿、核查、装订的全过程。

| 技能 | 作用 |
|---|---|
| bid-docs | 技术标（A3 四页）+ 附表生成，含清单工程量核算、横道图、总平面图 |
| bid-tender | 招标文件解析、废标红线清单、与旧模板逐页对照 |
| bid-package | 整册组装、章节顺序、暗标去痕、多标段交叉检查 |
| bid-pricing | 限价/安全文明费/签章/有效期/业绩资信核查 |
| doc-render | docx→PDF、页数核对、逐页截图校核 |

共用资产：`assets/scripts`（生成脚本）、`assets/templates`（附表模板）、`assets/references`（制图标准）。
